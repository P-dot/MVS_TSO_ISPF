# Security Review — Lab 02

## Scope

This review covers the evidence selected for public publication in Lab 02.

## Evidence selection

The original working document contained earlier login screens that duplicated Lab 01. Those screenshots were not copied into this lab.

The published evidence begins inside ISPF and is limited to the navigation actions needed to prove the Lab 02 objective.

## Review result

The selected evidence contains:

- ISPF menus and entry panels,
- the generic ADCD system identifier,
- the lab user ID `IBMUSER`,
- ISPF navigation commands.

The selected evidence does **not** contain:

- passwords,
- the ADCD sample credential table,
- IP addresses,
- MAC addresses,
- host adapter names,
- host-side network configuration,
- private network details.

## Text scan

The package text files were scanned for common private IPv4 and MAC-address patterns before ZIP creation.

## Publication decision

**Approved for repository publication.**
